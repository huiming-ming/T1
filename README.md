#COS30045 T01a

A small three-page website built with HTML, CSS and JavaScript. It will later host the data visualisations created in the other COS30045 tasks.

Live site: https://t1-sigma-ten.vercel.app/

## Pages

- Home
- Televisions
- About Us

Separate each page with individual html file for easy edit. JavaScript functions with the navigation clicks and marks the page the user is currently on.

## Project structure

```
index.html        Home page
televisions.html  Televisions page
about.html        About Us page
css/style.css     styling
js/script.js      header and footer, navigation, current page highlight, TV chart, estimate and table
images/           PowerIcon.png (logo)
```
